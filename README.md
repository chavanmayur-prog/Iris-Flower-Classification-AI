# Iris Flower Classification Using a Decision Tree

## Overview
This project uses a Decision Tree machine-learning algorithm to classify Iris flowers into three species using four flower measurements.

## Tools and Libraries
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook / Google Colab

## Dataset
The Iris dataset is loaded directly from `sklearn.datasets`, so no separate dataset download is required.

## How to Run
### Option 1: Google Colab
1. Open https://colab.research.google.com/
2. Select **File → Upload notebook**.
3. Upload `Iris_Flower_Classification.ipynb`.
4. Run all cells from top to bottom.

### Option 2: Run locally
1. Install Python 3.
2. Install dependencies:
   `pip install -r requirements.txt`
3. Start Jupyter:
   `jupyter notebook`
4. Open `Iris_Flower_Classification.ipynb` and run all cells.

## Workflow
1. Import libraries
2. Load and explore the dataset
3. Check data quality
4. Split into training and testing sets
5. Train a Decision Tree Classifier
6. Evaluate accuracy and classification metrics
7. Visualize feature importance and the decision tree
8. Predict the species of a new flower
